# Fast Crews

FastAPI that serves a purpose to be a gateway to multiagent AI flows orchestrated by notorious CrewAI

## List of Crews
- **Poets crew**. Consists of several poets agents competing for critic agent choice.

- Redis
- ARQ
- CrewAI
- OpenAI
- Openrouter
- LLMS
